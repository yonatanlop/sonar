¿Qué es SONAR?
Resumen ejecutivo

SONAR es una plataforma de inteligencia de redes sociales diseñada para detectar, analizar y alertar sobre menciones, narrativas y ataques dirigidos contra instituciones específicas en tiempo casi real. A diferencia de las herramientas genéricas del mercado, SONAR está construido para adaptarse a las necesidades particulares de cada organización monitoreada.

Capacidades principales

🔍 Rastreo de menciones
  • Keywords y aliases por entidad monitoreada
  • Búsqueda en Twitter/X, YouTube, Reddit y RSS
  • Filtro por idioma (español e inglés)
  • Deduplicación automática de menciones
🧠 Análisis NLP con IA
  • Análisis de sentimiento (positivo / negativo / neutral)
  • Detección de lenguaje de odio
  • Extracción de entidades nombradas (NER)
  • Clasificación de relevancia automática
🚨 Sistema de alertas
  • Alertas por Telegram, WhatsApp y correo
  • Umbrales configurables por tipo de ataque
  • Detección de picos anómalos de menciones
  • Motor de reglas personalizables
📊 Dashboard e informes
  • Panel en tiempo real con métricas clave
  • Evolución temporal de menciones
  • Mapa de calor por sentimiento
  • Exportación de reportes en PDF
🤖 Detección de bots
  • Clasificador ML de cuentas automatizadas
  • Perfil de comportamiento de cuentas
  • Detección de campañas coordinadas
  • Historial de actividad de autores
💬 Asistente IA (RAG)
  • Chat inteligente sobre las menciones recolectadas
  • Responde preguntas en lenguaje natural
  • Basado en Llama 3.1 vía Groq
  • Contexto semántico de todos los datos

El Problema
Por qué el monitoreo de redes sociales es crítico para las instituciones

Las instituciones religiosas, políticas, empresariales y civiles en Colombia y el mundo son objeto de campañas sistemáticas de desprestigio en redes sociales. Estas campañas operan de forma coordinada, utilizando cuentas reales y automatizadas para amplificar narrativas negativas, desinformación y ataques directos.

El problema sin monitoreo: Una campaña de ataques puede viralizarse en menos de 2 horas antes de que el equipo de comunicaciones de la institución tome conocimiento. Para ese momento, el daño reputacional puede ser irreversible.

¿Cómo operan los ataques en redes sociales?

① Publicación del ataque inicial (post, comentario, video)
→
② Amplificación por cuentas coordinadas o bots
→
③ Indexación en Google y tendencias en X
→
④ Recogido por medios de comunicación tradicionales
→
⑤ Daño reputacional consolidado e irreversible

¿Qué necesita una institución para protegerse?

Necesidad Sin SONAR Con SONAR

Monitoreo 24/7 ✗ Solo en horario laboral ✓ Ininterrumpido, incluyendo fines de semana
Identificación de bots y campañas ✗ Imposible sin herramientas ✓ Clasificador ML integrado
Historial de menciones ✗ Se pierde con el tiempo ✓ Base de datos permanente con búsqueda semántica
Alertas inmediatas al equipo ✗ Depende de quién vea el post ✓ Telegram, WhatsApp y correo automáticos
Análisis de sentimiento ✗ Subjetivo y manual ✓ IA multilingüe automática

Velocidad de Detección
Latencia desde la publicación hasta la alerta

SONAR opera mediante un modelo de consulta periódica (polling) que verifica cada plataforma en intervalos regulares. Una vez detectada una mención, el procesamiento NLP y la generación de alertas ocurren en menos de 5 minutos adicionales.

Latencia por plataforma (configuración actual)

PlataformaCiclo de scrapingNLP + AlertaLatencia máximaLatencia promedio
Twitter / X Cada 20 min +5 min ~25 min ~12 min
YouTube Cada 30 min +5 min ~35 min ~17 min
RSS / Noticias Cada 20 min +5 min ~25 min ~12 min
Reddit Cada 15 min +5 min ~20 min ~10 min
Facebook / Instagram* Con proveedor: cada 5 min +2 min ~7 min ~4 min

* Con integración de proveedor de datos licenciado via webhooks en tiempo real.

Con integración de proveedor de datos (webhooks)

Mejora con webhooks: Al integrar SONAR con un proveedor como Tooldata o Mention.com mediante webhooks, el proveedor notifica a SONAR en el momento exacto de detectar la publicación. La latencia se reduce de 10-25 minutos a 1-3 minutos en promedio, independientemente de la plataforma.

Acceso a Datos: La Realidad del Mercado
Twitter, Facebook e Instagram — por qué no existe una solución gratuita confiable

Desde 2023, las principales plataformas sociales han cerrado deliberadamente el acceso gratuito a sus datos. Esta es una decisión de negocio permanente, no un estado temporal.

Estado actual de cada plataforma

PlataformaAPI gratuitaBúsqueda de keywordsAlternativa oficialCosto mínimo
Twitter / X ✗ Eliminada 2023 ✗ Requiere pago API Basic $200/mes
Facebook ⚠ Solo páginas propias ✗ No disponible Graph API + proveedor Via proveedor
Instagram ⚠ Solo hashtags ✗ No texto libre Graph API + proveedor Via proveedor
YouTube ✓ Data API v3 ✓ Disponible Data API v3 Gratis
Reddit ⚠ Limitada ✓ Disponible PRAW / API oficial Gratis
Advertencia profesional: Cualquier solución que ofrezca acceso "gratuito" a datos de Twitter, Facebook e Instagram en 2026 lo hace a través de métodos que violan los Términos de Servicio de las plataformas. Estas soluciones pueden ser desactivadas sin previo aviso, representan un riesgo legal para el cliente y no son presentables en un contrato profesional.

¿Por qué los proveedores de datos licenciados son la solución correcta?

  • Legalidad: Tienen acuerdos formales con las plataformas para acceder y redistribuir datos públicos
  • Continuidad: Si una plataforma cambia su API, el proveedor asume el costo de adaptación
  • Confiabilidad: SLA documentados, soporte técnico, uptime garantizado
  • Presentable al cliente: Se puede mostrar en un contrato como un costo de infraestructura transparente
"El acceso a datos de Twitter, Facebook e Instagram tiene un costo de infraestructura porque las plataformas cobran por acceso oficial desde 2023. Cualquier solución que diga ser gratuita en estas tres redes viola los términos de servicio y puede ser desactivada sin previo aviso."
